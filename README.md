# ALSM

Functions and examples for applied linear statistical models.

Compatibility updates by Renova.

Corrects help page markup and argument documentation and structures the author metadata.

## Installation

```r
install.packages("ALSM", repos = c(
  Renova = "https://renova-r.r-universe.dev",
  CRAN = "https://cloud.r-project.org"
))
```

Version `0.2.0.9001` is based on [CRAN 0.2.0](https://cran.r-project.org/package=ALSM).
